## Cinema API

[Nest](https://github.com/nestjs/nest) API used for our cinema system.

## Project setup

```bash
$ pnpm install
```

## Compile and run the project

```bash
# watch mode
$ pnpm run start:dev

# production mode
$ pnpm run start:prod
```

## Run tests

```bash
# unit tests
$ pnpm run test

# e2e tests
$ pnpm run test:e2e

# test coverage
$ pnpm run test:cov
```
